# AQUATERRA.UZ

Адаптивный одностраничный сайт-визитка магазина аквариумных рыб, растений,
аквариумов и аксессуаров.

## Быстрая замена данных

Все данные клиента находятся в одном файле: `app/site-config.ts`.

Замените там:

- номер телефона;
- Telegram и Instagram;
- адрес и ссылку на карту;
- часы работы;
- путь к логотипу.

Чтобы добавить финальный логотип, положите файл в папку `public`, например
`public/aquaterra-logo.png`, затем укажите в `logoSrc` значение
`/aquaterra-logo.png`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который появится после запуска.

## Проверка перед публикацией

```bash
npm test
```

Проект совместим с Cloudflare Workers через vinext и уже содержит необходимую
конфигурацию Sites для деплоя.
